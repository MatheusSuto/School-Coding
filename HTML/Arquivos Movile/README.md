## Prompt:

atue como um dev front end especialista em mobile e UX/UI design.
crie o código para um app web mobile chamado "Minha Rotina de Estudos". O objetivo dele é ajudar alunos a organizar tarefas da escola para não perderem prazos.
O que o app precisa:
formulário simples para cadastrar( nome da tarefa, disciplina e data de entrega).
botão visível de "Adicionar Tarefa".
lista para mostrar todas as tarefas já cadastradas.
opção de marcar a tarefa como concluída (deixando o texto riscado).
opção de excluir uma tarefa.
contador que atualize em tempo real mostrando quantas tarefas ainda faltam fazer.
técnicallity:
entregue tudo num único arquivo html(com o css e js dentro).
visual  moderno, parecendo um app de celular de verdade, com botões grandes e fáceis de clicar (acessibildiade).
faça alguma coisa para que os dados não sumam ao fechar/recarregar a página.
